# Política de devoluciones de EcoMarket

Versión 4.2 · Vigente desde el 1 de enero de 2026

Este documento es la fuente de verdad sobre devoluciones. Cualquier respuesta entregada a un
cliente debe apoyarse exclusivamente en las reglas aquí consignadas.

## 1. Plazos generales

| Concepto                                          | Regla                                                    |
| ------------------------------------------------- | -------------------------------------------------------- |
| Plazo para solicitar la devolución                | 30 días calendario desde la fecha de entrega             |
| Plazo para despachar el producto una vez aprobada | 8 días calendario                                        |
| Tiempo de revisión en bodega                      | 3 días hábiles tras la recepción                         |
| Tiempo de reembolso                               | 5 a 10 días hábiles después de la revisión               |
| Costo del transporte de retorno                   | Gratuito mediante la guía prepagada que genera EcoMarket |

## 2. Categorías que admiten devolución

| Categoría           | Condición exigida                                             |
| ------------------- | ------------------------------------------------------------- |
| Hogar               | Producto sin uso, con empaque original y accesorios completos |
| Textiles            | Sin uso, con etiquetas adheridas y sin olores ni manchas      |
| Electrónica         | Con empaque, cables y manual; se verifica el número de serie  |
| Papelería y oficina | Sin uso y sin marcas de escritura                             |

## 3. Categorías que NO admiten devolución

Por razones sanitarias y de inocuidad, los siguientes productos no se reciben de vuelta una vez
entregados:

| Categoría                            | Motivo                                                                     |
| ------------------------------------ | -------------------------------------------------------------------------- |
| Alimentos perecederos                | No es posible garantizar la cadena de frío ni la inocuidad tras la entrega |
| Higiene personal                     | Riesgo sanitario cuando el sello o empaque ha sido abierto                 |
| Cuidado corporal y cosmética         | Riesgo sanitario cuando el producto ha sido destapado o usado              |
| Productos personalizados o grabados  | Fabricación hecha a la medida del cliente                                  |
| Tarjetas de regalo y bonos digitales | Entrega inmediata y no reversible                                          |

## 4. Excepciones que siempre aplican

Aun cuando la categoría figure como no retornable, EcoMarket responde cuando el problema es
atribuible a la empresa. En estos casos se ofrece **reposición del producto o reembolso total**,
a elección del cliente, sin exigir la devolución física del artículo:

1. El producto llegó averiado, derramado o con el empaque violado.
2. El producto llegó vencido o con menos de 15 días para su fecha de vencimiento.
3. Se despachó una referencia distinta a la comprada.
4. El pedido llegó incompleto respecto a la factura.
5. El producto presenta un defecto de fabricación dentro de la garantía legal.

Para activar una excepción se solicita al cliente una fotografía del producto y del empaque. La
evidencia se registra en el caso y no se exige que el cliente devuelva alimentos ni artículos de
higiene.

## 5. Proceso de devolución

1. El cliente solicita la devolución indicando el número de seguimiento del pedido.
2. Se verifica que el pedido esté en estado **Entregado** y dentro de los 30 días de plazo.
3. Se valida la categoría del producto contra las secciones 2 y 3 de esta política.
4. Si procede, se genera el número de caso `DEV-AAAA-NNNN` y la guía prepagada de retorno.
5. El cliente empaca el producto y lo entrega en el punto de la transportadora.
6. Bodega revisa el estado del artículo.
7. Se emite el reembolso al medio de pago original o, si el cliente lo prefiere, como saldo a favor.

## 6. Situaciones que requieren intervención de un agente humano

El asistente no resuelve estos casos por su cuenta; debe recogerlos, explicar el siguiente paso y
derivarlos al equipo humano:

- Reclamaciones por garantía legal o solicitudes de indemnización.
- Pedidos entregados hace más de 30 días.
- Inconformidades reiteradas del mismo cliente sobre el mismo pedido.
- Cobros duplicados, fraudes o disputas con la pasarela de pago.
- Manifestaciones explícitas de molestia grave, amenazas de acción legal o daño a la salud.
- Solicitudes de eliminación de datos personales.

## 7. Reglas de comunicación

- No se prometen fechas, montos ni excepciones que no estén en este documento.
- No se solicitan al cliente datos sensibles como números completos de tarjeta o contraseñas.
- Cuando la devolución no procede, se explica el motivo con claridad y se ofrece siempre una
  alternativa: excepción aplicable, asesoría de uso, saldo a favor por cortesía comercial cuando
  esté autorizado, o contacto con un agente humano.
